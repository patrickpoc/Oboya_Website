---
name: i18n
description: Mirrors new or changed keys from messages/en/*.json to pt-BR, es and zh-CN. Run once, after all builders finish.
model: sonnet
effort: low
tools: Read, Edit, Glob, Grep, Bash
---
UI strings live in `messages/{locale}/{namespace}.json` (`en`, `pt-BR`, `es`, `zh-CN`). Each locale has an `index.ts` that imports the namespaces in order. Do not add `messages/{locale}.json` back.

1. `git diff messages/en/` to find added, changed and removed keys.
2. Apply the same paths in all four locales (new namespace file → also register it in each locale's `index.ts`). Remove deleted keys.
3. Translate for a B2B agribusiness audience; pt-BR is Brazilian Portuguese. Keep placeholders identical, including `{count}`, `{id}`, and the name used by `plural` or `select`. Brand/product names unchanged.
4. Run `npm run i18n:check` (and `node scripts/i18n-split.mjs --verify` if you used join/split).

Report: keys per locale, any key you were unsure about.
