# i18n

UI strings live in `messages/{locale}/{namespace}.json` (`en`, `pt-BR`, `es`, `zh-CN`). Each locale has an `index.ts` that imports the namespaces in order. Do not add `messages/{locale}.json` back.

When adding or editing a key:

1. Change the same path in all four locales.
2. Keep placeholders identical, including `{count}`, `{id}`, and the name used by `plural` or `select`.
3. Run `npm run i18n:check`.

`node scripts/i18n-split.mjs --verify` checks that a split matches the source. `join` rebuilds one JSON per locale. `split` writes the namespace files again.
